# Umbral

A desktop password manager with an instant autofill overlay for the Riot Client (League of Legends & Valorant).

## Download & Installation

Grab the latest version from the [Releases](https://github.com/angelsarenotreal/Umbral/releases) page:

- **Installer (`Umbral.Setup.1.0.0.exe`)** — *Recommended*: Standard Windows setup that installs Umbral and adds desktop/Start menu shortcuts.
- **Portable (`Umbral.1.0.0.exe`)**: No installation needed. Download and run it directly.

## Getting Started

1. Open Umbral and create your master password to set up your encrypted local vault.
2. Add your Riot accounts (summoner name, username, password, region).
3. Open the Riot Client login window.
4. Click the Umbral icon on the client artwork to open your vault and autofill with one click.

## Features

- **Local AES-256-GCM Encryption**: Your vault is encrypted locally on your machine with your master password.
- **Riot Overlay Dock**: Clean floating trigger button docked right on the Riot Client.
- **Instant Autofill**: Injects credentials into login fields in one click without copy-pasting.
- **Live Summoner Stats**: Auto-syncs rank, LP, and profile icons from OP.GG.
- **Password Generator**: Built-in generator for new accounts and smurfs.
