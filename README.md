# Umbral

## Download & Installation

Download the installer from the [Releases](https://github.com/angelsarenotreal/Umbral/releases) page:

- **`Umbral.Setup.1.0.0.exe`**: Run the setup wizard to install Umbral.

## Getting Started

1. Open Umbral and create your master password to set up your encrypted local vault.
2. Add your Riot accounts (summoner name, username, password, region).
3. Open the Riot Client login window.
4. Click the Umbral icon on the client artwork to open your vault and fill in your credentials.

## Features

- **Local AES-256-GCM Encryption**: Your vault is encrypted locally on your machine with your master password.
- **Riot Overlay Dock**: Floating trigger button docked right on the Riot Client login window.
- **Live Summoner Stats**: Auto-syncs rank, LP, and profile icons from OP.GG.
- **Password Generator**: Built-in generator for new accounts and smurfs.
